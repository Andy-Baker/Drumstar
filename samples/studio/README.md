# Studio Kit – Samples

Quelle: **SM Drums** ("Deeply Sampled Free Drums") von Scott McLean, Tod Stillwell und Suleiman Ali,
veröffentlicht als **Public Domain** (https://sfzinstruments.github.io/drums/sm_drums, Repo github.com/sfzinstruments/SMDrums).

Aufbereitung: Stereo-Mixdown → mono, gekürzt mit Ausblenden, je Stimme auf das lauteste Layer normalisiert, MP3 (LAME VBR q4).

Dateinamen: `<stimme>_v<layer>_r<roundrobin>.mp3`
- Layer 1–4 = Ghost leise, Ghost, Normal, Akzent (gewählt nach Pegel ca. −19 / −12 / −5 / 0 dB unter dem lautesten Schlag)
- Round-Robin 1–3 = RR1–RR3 der Bibliothek, gleiche Anschlagstärke
