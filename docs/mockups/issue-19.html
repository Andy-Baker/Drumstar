Worum es geht

Im Code stehen 65 Stellen unter 11 px (6–10 px). Das Mockup zeigt die wichtigsten Bereiche.

Varianten

A · nur Größe: alles mind. 11 px, Layout bleibt. Lange Texte werden mit … gekürzt (Mixer-Namen, Regler-Labels).

B · Größe + Platz: mind. 11 px und dort Platz geschaffen, wo es eng wird: Mixer-Kanäle breiter (62→74 px, weniger Kanäle gleichzeitig sichtbar), Regler 4 pro Zeile, Step-Nummern nur 1·5·9·13, Pad-Status nur auf aktivem Pad.

„Größe zeigen“ anhaken und Text antippen = Schriftgröße.
